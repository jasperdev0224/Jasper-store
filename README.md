Jasper Store

My first React project — a product store built with reusable components and props instead of repetitive code.

Features

- Reusable ProductCard component
- Product data passed through props
- Multiple products rendered dynamically
- Clean and simple user interface
- Responsive design

Technologies Used

- React
- JavaScript
- HTML
- CSS

What I Learned

This project was my introduction to React. I learned how to create reusable components, pass data using props, and render multiple products without repeating the same markup.
